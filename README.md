# 💗 Neon Pink Heart Stars

A Python Turtle animation where hundreds of stars move smoothly from random positions and form a glowing neon-pink heart.

## ✨ Features

- Smooth star animation
- Neon pink color
- Heart-shaped particle formation
- Random starting positions
- Uses Python Turtle graphics
- No external Python packages required

## 🛠️ Requirements

- Python 3.x
- Tkinter/Turtle support
